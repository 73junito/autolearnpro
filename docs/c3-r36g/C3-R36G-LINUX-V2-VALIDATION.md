## 6. Cross-machine verification — evidence from one machine, verified on another

The strongest result of this milestone. Evidence produced **on Windows** was verified **on Linux** by a verifier that
re-derived the snapshot from its own tree and read the toolchain version from its own install:

| Artefact | Produced on | Size | SHA-256 |
| --- | --- | --- | --- |
| `evidence.json` | Windows (Node 24) | 1,231 B | `1f46a2570f91d44c9a0ff97e12a176b59575111cca452e57fb8b5b23f78f7804` |
| `worker.mjs` bundle | Windows (esbuild 0.28.2) | 579 B | `a955e25fbb32a6cd5677091ffe24db7a04355821ee76fd7aead547e6d234278a` |

Linux verifier result (`logs/crossmachine-verification.log`), exit **0**:

```
{"ok":true,"verifier":"evidence-verifier.cli","pid":142940,
 "source":{"sha256":"261732ecb9accae4…","bytes":613},
 "artifact":{"path":"worker.mjs","bytes":579,"sha256":"a955e25fbb32a6cd…"},
 "snapshot":{"schema":"alp-c3-r36a-multi-root-snapshot","combinedSha256":"58d5eccc1babe486…"},
 "toolchain":{"name":"esbuild","version":"0.28.2","configId":"alp-c3-r36b-worker-bundle-v1"},
 "claims":{"sourceCommitVerified":false,"ciAttested":false,"publicationAuthorized":false,"deployAllowed":false}}
```

**All four digests match the Windows values exactly**, and the Linux process re-derived them from its own copy of the
source rather than trusting the envelope. The verified Linux-side inputs were the transferred evidence and bundle,
copied byte-for-byte (`sha256sum` printed in the log), verified against a `/tmp`-rooted temporary policy.

Two limitations, stated rather than glossed:

1. **No absolute path may appear in an envelope** — which is why this works at all. The envelope records
   repository-relative paths and content digests only; nothing in it is machine-specific.
2. **The two machines are not independent forges.** The Linux tree is a byte-identical copy of the Windows tree, so
   the snapshot agreement shows the *contract* is machine-neutral, not that an independent checkout would agree. A
   genuinely independent checkout is the remaining step (B13 stays open for that).
